# Céleste

Application navigateur à ouverture directe. Le paquet AES-GCM possède une enveloppe publique : ce n’est pas un contrôle d’accès.

La mémoire locale est chiffrée. Une sauvegarde cloud, chiffrée sur l’appareil avant envoi, est disponible seulement avec un accord distinct et un code de récupération à conserver. Aucun service de stockage ne peut retrouver ce code.

Voix française : Piper SIWIS, modèle et binaires vérifiés avant usage, téléchargés au premier usage puis mis en cache. Notices et sources correspondantes sous app/vendor/piper/. Anglais : voix de l’appareil, différente.

Distribution navigateur uniquement ; aucune APK nouvelle. Paiement en ligne non activé, bouton Test gratuit séparé des prix affichés.
